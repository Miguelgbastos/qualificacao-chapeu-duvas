# Qualificação · Chapéu d’Uvas

Site da apresentação de exame de qualificação de Mariana Martins Marcelino (PPGEC/UFJF): modelagem hidrológica da barragem Chapéu d’Uvas para eventos extremos.

## Como apresentar

```bash
npm install
npm run dev
```

Abra o endereço local, pressione `F` para tela cheia e use as setas para navegar.
